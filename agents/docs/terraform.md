# Terraform

Read this before you edit `.tf` files.

- Write comments in lowercase plain English. Start each comment with a verb: `# allow egress to the vpc endpoint`.
- Use a plain `#` comment. Do not use banner comments such as `# --- Section ---`.
- Keep each variable description to 3-8 words.
- Do not add a comment to code that is obvious.
- Never use an em dash. Use a hyphen (-).
