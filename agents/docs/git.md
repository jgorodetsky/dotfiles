# Git

Read this before you commit, push or open a pull request.

- Commit or push only when I ask.
- Keep each commit to one topic. Copy the subject style from `git log` in that repo. Say why in the body when the reason is not clear.
- Never credit yourself or another agent. A commit gets no co-author line. A pull request gets no "Generated with" footer.
- My commits have a GPG signature, so a passphrase prompt can open. Tell me before you commit.
- Before you commit to a public repo, read `git diff --staged`. Remove secrets, tokens and personal details.
